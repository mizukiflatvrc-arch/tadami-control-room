- Node.js 22.23.2 / npm 10.9.8。
- React 19.3.0 / TypeScript 6.0.3 / Vite 8.3.4。
- Vitest 5.0.3 / Playwright 1.64.0 / Chromium 156.0.8078.4。

- Chromium 用の不足ライブラリ（libnspr4 / libnss3）は `/tmp/tadami-browser-libs/` に展開し、検証プロセスだけ `LD_LIBRARY_PATH` で参照。OS のパッケージ設定は変更していない。この一時パスはアプリやテスト設定には含めない。

## 検証項目

| 分類 | 内容 |
| --- | --- |
| 型検査・lint | アプリ・テスト・ツール設定の型検査、ESLint |
| 単体・結合 | 使用率の計算、閾値境界、期待停止、総合判定、不正データ・未来時刻、データ鮮度 |
| 取得処理 | 初回失敗、前回値保持、自動復旧、タイムアウト、二重取得防止、取消、古い応答の無視 |
| タブ | 非表示時の停止と復帰時の即時取得 |
| 履歴 | 欠損区間、間隔の抜け、最大 61 点、現在値と履歴の整合性 |
| 基準画面 | 1280×1024 / 1280×900。全パネル・フッター・開発用操作が画面内に収まる |
| 狭幅 | 390×844 / 320×740 / 768×1024 / 640×512。横方向にはみ出さない |
| 拡大 | CSS 200% 拡大、および 1280×1024 のブラウザー 200% 拡大相当の表示領域 640×512 |
| 多数・長い行 | ストレージ 10 行・サービス 20 行を 1280 / 390 / 320px 幅で確認 |
| シナリオ | 正常、注意、各種異常、部分欠損、異常と欠損、履歴欠損、全取得失敗、更新遅延、復旧 |
| 操作性 | キーボード操作、フォーカス、デスクトップ・スマートフォンの axe 検査 |
| 通信 | 実行時のページ要求がすべてローカル同一オリジン内に収まる |
| 継続更新 | 仮想時計の 1 時間分で履歴・タイマー・DOM 数が増え続けず、再取得と稼働時間が更新される |

## 検証の限界と後続作業

- 1 時間分の連続更新は仮想時計を使った加速試験。実時間で 1 時間以上の常時表示・メモリ推移は未確認。
- スマートフォンは Chromium のビューポートで検証する。実端末の Safari / Firefox、本体モニター、実際のブラウザーメニューによる拡大は未確認。
- 日本語フォントは OS 環境により字幅が異なる。実機フォントでの最終確認は本番接続段階で行う。
- Prometheus / Grafana / exporter / 実サービスの検証、本番配備は段階 5 以降の範囲。

テストコマンドと起動手順は [README](../README.md) を参照。
